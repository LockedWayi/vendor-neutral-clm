# Learning log

One entry per session, `YYYY-MM-DD.md`, written in Turkish and kept
short. The entry is for the person who did the session, a week later:
what was built, what was understood, and whether it stuck.

Template:

```markdown
# YYYY-MM-DD

## Bugün ne kurduk / öğrendik
- …

## Kavramlar
- **<kavram>:** iki üç cümle. Gerçek hayatta (kurumsal CLM'de) karşılığı: …

## Üç soru
1. …
2. …
3. …

## Bir sonraki adım
- …
```

Rules: no secrets, no real domain, no employer or customer name. An entry
records what was done and run; a claim about the system that was not
verified in the session is written as not verified.
